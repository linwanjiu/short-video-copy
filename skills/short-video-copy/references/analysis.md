# 拆解模式

用户给的是**参考视频**而不是选题时走这里：先拆，再给改写方向。
输入可以是链接，也可以是他手打的一段文字稿。

---

## Step 1 拿到材料

- 有链接：先尝试抓标题、描述、字幕
- 抓不到：请他贴文案/字幕，或口述前三句
- 只有前三句也能分析，但要在输出开头注明"信息不完整"

**不要编造播放量、点赞数。** 没有的指标写 N/A。

## Step 2 拆六件事

### 2.1 数据面板（有就填）

| 平台 | 作者 | 时长 | 播放 | 点赞 | 评论 | 互动率 |
|---|---|---|---|---|---|---|

互动率 =（点赞 + 评论）/ 播放。

### 2.2 Hook（前 3 秒）

- 原句摘录
- 归类：反常识 / 好奇缺口 / 具体数字 / 身份点名 / 利益承诺 / 冲突 / 故事 / 自白
- 强度判断：为什么能让人停下来（要具体，不要说"因为很吸引人"）
- 如果不够强：给一版改写

### 2.3 结构分段

| 段落 | 时间 | 内容 | 作用 |
|---|---|---|---|

典型结构：Hook → 问题/背景 → 方案/揭示 → 证据/例子 → 收口。
标出**转折点在哪一帧**，以及"哪里容易流失"。

### 2.4 风格标签（多选）

- 呈现：真人出镜 / 纯配音 / 字幕流 / 短剧 / 蒙太奇 / 录屏 / 采访
- 类型：科普 / 娱乐 / 叙事 / 测评 / 教程 / 观点 / 资讯
- 情绪：紧迫 / 好奇 / 幽默 / 震惊 / 共鸣 / 权威

### 2.5 为什么能爆

2–3 条，每条要能落到具体手法。
反例："因为内容好"。正例："开头用 $0→$10K 的数字反差，3 秒内给出价值承诺，第 7 秒才出现品牌"。

### 2.6 三个改写方向

每个方向给：角度一句话 + 改写后的 hook + 适合平台。

---

## Step 3 输出

按 2.1–2.6 顺序，用表格和小标题，中文输出，术语保留英文（hook、CTA、talking head）。

## Step 4 存进素材库

如果用户在做系列研究，把结论追加到 `examples/analyzed/` 下：
日期 + 作者 + 主题 + hook 类型 + 为什么爆 + 可借鉴点，一行一条，方便后面横向找规律。
