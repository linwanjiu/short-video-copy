# 平台预设

平台的差别不在"哪个火"，在**观众的心智状态**：抖音是"随便刷刷"，小红书是"我在找答案"，视频号是"我认识的人在说话"，B站是"我准备花时间"。

---

## 抖音

- **时长**：15–45 秒，超过 60 秒必须有强剧情
- **节奏**：每 3–5 秒一个信息点，不许有一秒空镜
- **口播字数**：每秒 4–5 字，15 秒 ≈ 65 字
- **开头**：0.5 秒内出画面上字，第一句就是钩子，没有寒暄
- **字幕**：全程大字幕，关键词变色；不用长句
- **CTA**：关注 / 评论区扣数字 / 看合集
- **算法偏好**：完播率 + 互动率，所以结尾要留一个"值得评论"的问题
- **常见坑**：前 3 秒放 logo、片头动画、"欢迎来到我的频道"——直接掉一半
- **合规**：绝对化用语、医疗功效、金融收益承诺，这三类查得最严

## 小红书

- **时长**：20–60 秒，图文和视频混发
- **节奏**：慢一点，允许停顿和情绪，但要"有用"
- **口播字数**：每秒 3.5–4 字
- **开头**：先给身份或场景（"作为一个……"），再给结论
- **画面**：真人出镜 > 纯字幕；封面决定 70% 的点击
- **CTA**：收藏 / "评论区告诉我你的情况" / 主页链接
- **算法偏好**：收藏率 + 搜索长尾，标题要能被搜到
- **常见坑**：太像抖音（节奏太快、语气太冲）会显得不真诚
- **合规**：功效类词（美白、祛痘、减肥）必须谨慎；不能写"最"

## 视频号

- **时长**：30–90 秒，允许更长
- **节奏**：像跟熟人说话，可以有铺垫
- **口播字数**：每秒 3.5 字左右
- **开头**：一句话点题即可，不要求强钩子——社交推荐本来就带信任
- **人群**：偏中年、偏实用、偏"转发给家人"
- **CTA**：点赞 / 转发 / 关注，**"转发"的权重比抖音高**
- **算法偏好**：社交关系链扩散，所以内容要"值得转给某个人"
- **常见坑**：照搬抖音那套"你越……越……"会显得油
- **合规**：健康、养生类内容审核严，别做疗效暗示

## B站

- **时长**：60 秒–10 分钟，短的是"切片"
- **节奏**：可以慢，但信息密度要高，观众愿意等
- **口播字数**：每秒 4 字
- **开头**：允许 5–10 秒铺垫，但要明确"这期讲什么、为什么值得看"
- **画面**：屏幕录制、图表、分屏都受欢迎
- **CTA**：三连 / 关注合集
- **算法偏好**：完播 + 弹幕 + 收藏，长视频权重高
- **常见坑**：把 15 秒抖音稿拉长到 3 分钟——信息不够，会被"太长不看"
- **合规**：相对宽松，但引用必须给出处

## 通用（没有明确平台时）

按抖音的节奏写，去掉平台特有的话术：15–30 秒，每秒 4 字，钩子 + 结论 + 一个论据 + 收口。
好处是任何平台都能发；坏处是哪个平台都不算最优。

## 跨平台复用

一条内容要发多平台，改这四样就够，不用重写：

| 改什么 | 怎么改 |
|---|---|
| 开头 3 秒 | 抖音用反常识，小红书用身份，视频号用结论 |
| 语速 | 抖音 4.5 字/秒，小红书 3.8，视频号 3.5 |
| 结尾 CTA | 抖音问问题，小红书求收藏，视频号求转发 |
| 标题 | 抖音靠钩子，小红书靠关键词（能被搜到） |
