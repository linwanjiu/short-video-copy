# 语句与标点规范

文案是要被念出来、也要被看到的。**读起来顺、看起来对**，这两件事都靠标点。
写完后逐条过一遍，不合格就改。

---

## 一、标点（全部用全角）

| 用这个 | 不要用 | 示例 |
|---|---|---|
| `，` | `,` | 睡不够，欠的不是时间 |
| `。` | `.` | 是节奏。 |
| `！` `？` | `!` `?` | 真的吗？ |
| `：` `；` | `:` `;` | 只有一个标准：同一时间醒 |
| `（）` | `()` | 周末（尤其是周日） |
| `「」` 或 `“”` | `""` | 他说「不用改」 |
| `……`（六点） | `...` 或 `…` | 我试过……没用 |
| `——`（两个） | `—` 或 `--` | 真相是——你欠着债 |
| `《》` | `<>` | 《睡眠革命》 |

**引号统一用一种**，全篇不要「」和“”混用。嵌套时用『』。

## 二、断句

1. **一句只说一件事**。两个意思就断成两句。
2. **单句 ≤ 15 字**（口播节奏）。超过就在逗号处断开。
3. **一个句子里逗号不超过 2 个**。第 3 个逗号出现，说明该断句了。
4. **不要一逗到底**：

   - ❌ 你越补觉越累，因为睡不够欠的不是时间是节奏，周末睡到中午等于每周倒一次时差。
   - ✅ 你越补觉，越累。睡不够，欠的不是时间，是节奏。周末睡到中午，等于每周倒一次时差。

## 三、用词

| 不要 | 改成 |
|---|---|
| 进行优化 / 加以调整 | 改 / 调 |
| 的话（多余） | 删掉 |
| 非常非常 / 特别特别 | 删一个，或换具体描述 |
| 众所周知、毫无疑问 | 删掉（没有信息量） |
| 赋能、闭环、抓手、颗粒度 | 换成人话 |

## 四、数字与英文

- 数字用阿拉伯数字：`15 秒`、`3 个`、`8 小时`
- **数字和中文之间不加空格**：`15秒` ✅ / `15 秒` ❌
- 数字和英文单位之间加半角空格：`15 s`、`1080 P` 视排版而定，正文里优先写中文单位
- 百分号紧跟数字：`73%`
- 英文单词前后各加一个半角空格：`用 Remotion 渲染`
- 英文缩写首次出现给中文：`ASR（语音识别）`

## 五、常见反例

| 反例 | 问题 | 改法 |
|---|---|---|
| `你知道吗?` | 半角问号 | `你知道吗？` |
| `我试了...` | 三点省略号 | `我试了……` |
| `他说"不行"` | 半角引号 | `他说「不行」` |
| `第一，第二，第三，` | 逗号当分隔符 | 分行，或用 `、` |
| `15 秒` | 数字后多空格 | `15秒` |
| `真的！！！` | 连用感叹号 | `真的。` 或 `真的！` |
| `A、B、C。` | 顿号用于并列短语 ✅ | 并列词用 `、`，并列句用 `；` |

- [ ] 引号统一，没有混用
- [ ] 省略号是 `……`（六点）
- [ ] 破折号是 `——`（两个）
- [ ] 每句 ≤ 15 字，逗号 ≤ 2 个
- [ ] 没有一逗到底的长句
- [ ] 数字格式统一（15秒 / 73%）
- [ ] 英文前后有空格
- [ ] 没有「赋能」「闭环」这类词
