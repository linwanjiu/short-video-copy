# 示例：一句话 → 一套文案

> 这份示例演示的是**用户要了分镜表**的版本。默认交付只到「文案 + 发布文案」为止。

**输入**：「讲一下为什么你总是睡不够」

**参数**：`platform: 通用` `category: 通用` `tone: 清晰直接` `duration: 30` `cta: 关注`

**计时**：`node scripts/timing.mjs --rate 4.2 ...`，结果 29.5s / 104 字，误差 0.5s 以内。

## 自检

- [x] 前 3 秒是反常识钩子，「你越……越……」
- [x] 钩子只用了「反常识」一类，没有串类
- [x] 可截图句：「睡够不是八小时，是每天同一时间醒」
- [x] 有具体数字：八小时、每周一次、这周
- [x] 无「大家好」「今天聊聊」
- [x] 每句 ≤ 15 字，最长 15 字
- [x] 总时长 29.5s，目标 30s，误差 0.5s
- [x] 无绝对化用语，未承诺疗效
- [x] 结尾动作明确：关注
