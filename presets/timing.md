# 计时模型

时间必须**算**，不能估。估出来的时间永远对不上台词。

---

## 公式

```
单句时长 = 字数 / 语速 + 0.2 × 逗号数 + 0.35 × 句号数
累计时间 = 上一句结束时间
```

- **字数**：只数汉字和数字，不数标点
- **句号**：包括句号、问号、感叹号
- **逗号**：包括逗号、顿号、分号、破折号

## 语速表（字/秒）

| 平台 | 常规 | 快节奏（情绪强） |
|---|---|---|
| 抖音 | 4.5 | 5.0 |
| 小红书 | 3.8 | 4.2 |
| 视频号 | 3.5 | 3.8 |
| B站 | 4.2 | 4.6 |
| 通用 | 4.2 | 4.5 |

## 容量反推

定好时长后，先算**能装多少字**：

```
可用字数 ≈ 时长 × 语速 − 停顿开销
停顿开销 ≈ 总标点数 × 0.28 秒 × 语速
```

简化版（经验值）：

| 时长 | 抖音 | 小红书 | 视频号 |
|---|---|---|---|
| 15s | 55 字 | 45 字 | 42 字 |
| 30s | 115 字 | 95 字 | 88 字 |
| 45s | 175 字 | 145 字 | 135 字 |
| 60s | 235 字 | 195 字 | 180 字 |

**先按这个表控制字数，再算精确时间。** 顺序反了就必然超时。

## 镜头时长约束

| 约束 | 处理 |
|---|---|
| 单镜头 < 1.2 秒 | 太快，观众看不清，合并或删掉 |
| 单镜头 > 6 秒 | 太慢，容易划走，拆成两个画面 |
| 钩子镜头 | 建议 1.5–2.5 秒，要留出"停住手"的时间 |

## 分镜与口播的关系

**分镜的时间必须从口播表复制，不许独立分配。**

- 一句台词 = 一个镜头：时间列直接照抄
- 一句台词 = 两个镜头：拆成 `1a` / `1b`，父级时间不变，子镜头按画面节奏分，但**加起来必须等于原句时长**
- 合并两句成一个镜头：合并后的时间 = 两段时间相加

## 校验

交稿前算一遍：

```
末尾时间 − 目标时长  ≤ 0.5 秒
```

超了先删字，不要靠"念快点"糊过去。语速是物理约束，不是建议。
