# 品类预设

品类决定**结构骨架**：先说什么、后说什么、最后要观众干什么。
同一个选题，换个品类，结构完全不同。

---

## 通用

没有明确品类时用：**口播骨架 + 科普内核**。最不容易出错，也最容易超时。

| 段落 | 占比 | 任务 |
|---|---|---|
| 钩子 | 10% | 反常识或具体数字 |
| 结论 | 15% | 一句话给答案，不铺垫 |
| 两个论据 | 45% | 每点一个机制 + 一个例子 |
| 收口 | 15% | 一句可截图的话 |
| 动作 | 15% | 按 profile 的 cta |

- 两个论据就够。第三个通常是凑数，还容易把时长撑爆
- 常见错误：当成知识科普写，论据堆到四个，必然超时

## 知识科普

**目标**：让观众获得一个能转述给别人的结论。

| 段落 | 占比 | 任务 |
|---|---|---|
| 钩子 | 10% | 反常识或数字，打破一个默认认知 |
| 结论 | 10% | 先给答案，不铺垫 |
| 论据 1–3 | 60% | 每点一个机制 + 一个具体例子 |
| 反常识转折 | 15% | 推翻一个常见做法 |
| 收口 | 5% | 一句可截图的话 |

- 必备：至少一个**机制解释**（为什么会这样），否则只是复述常识
- 常见错误：论据全是"研究表明"，没有具体场景

## 带货

**目标**：让观众相信"这个东西解决我的问题"。

| 段落 | 占比 | 任务 |
|---|---|---|
| 钩子 | 10% | 痛点场景，不是产品介绍 |
| 痛点确认 | 15% | 说出他没说出口的麻烦 |
| 方案 | 20% | 产品登场，只讲一个核心卖点 |
| 证据 | 25% | 对比、实测、细节特写、真实使用 |
| 价格锚点 | 15% | 和什么比便宜 / 值在哪 |
| CTA | 15% | 明确动作 + 降低决策风险（退换、试用） |

- 必备：**一个具体使用场景**，不是参数罗列
- 常见错误：一上来念参数；说"性价比高"却不说跟谁比
- 合规：不能承诺效果，不能伪造原价，"最"字禁用

## 个人 IP

**目标**：让观众记住"这个人怎么想问题"。

| 段落 | 占比 | 任务 |
|---|---|---|
| 钩子 | 10% | 一个观点或一个反差经历 |
| 立场 | 15% | 明确表态，不含糊 |
| 故事 | 35% | 一件具体的事，有时间地点人物 |
| 提炼 | 25% | 从故事里抽出一条可复用的判断 |
| 收口 | 15% | 邀请对话，不是求关注 |

- 必备：**一件真事**，细节越具体越可信
- 常见错误：全是观点没有故事，或者故事讲完没有提炼

## 剧情

**目标**：让人看完，且想看下一条。

| 段落 | 占比 | 任务 |
|---|---|---|
| 冲突 | 15% | 一开场就在矛盾里 |
| 升级 | 30% | 矛盾变严重 |
| 反转 | 25% | 意料之外，情理之中 |
| 落点 | 20% | 一句台词点题 |
| 钩子 | 10% | 留一个未解的问题 |

- 必备：**一个反转**，且反转要能回看成立
- 常见错误：为了反转而反转，人物动机断裂

## 口播

**目标**：把一段话说得让人听得下去。

| 段落 | 占比 | 任务 |
|---|---|---|
| 钩子 | 10% | 一句话立住 |
| 三个点 | 70% | 并列结构，每点一句总结 + 一句展开 |
| 收口 | 20% | 回到开头那句话，形成闭环 |

- 必备：**结构感**，观众要能数得出来"第一、第二、第三"
- 常见错误：并列点长度不一，或者第三点明显凑数

---

## 品类混搭

可以混，但要有主次：

- **科普 + 带货**：先科普建立信任，最后 15 秒转产品（常见的"知识型带货"）
- **IP + 剧情**：用剧情演自己的观点
- **口播 + 科普**：最稳的组合，适合新手

不要混的：剧情 + 带货（除非本身就是短剧带货，那需要另一套脚本）
